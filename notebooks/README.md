
# Weekly lecture notebooks

This folder contains the 14 weekly lecture notebooks for the STM32F103C8T6 course. The lecture material is primarily in French; practical English-language GPIO, TIM, PWM, and ADC exercises are in [`../workshops/README.md`](../workshops/README.md).

For the authoritative course outline and schedule, see the [French syllabus](../syllabus/README.md).

| Week | Lecture topic | Notebook |
|---:|---|---|
| 1 | Introduction and ARM Cortex-M3 architecture | [Week 1](mcu_notes_week01.ipynb) |
| 2 | STM32F103C8T6 hardware architecture | [Week 2](mcu_notes_week02.ipynb) |
| 3 | GPIO: HAL, LL, and registers | [Week 3](mcu_notes_week03.ipynb) |
| 4 | EXTI and NVIC | [Week 4](mcu_notes_week04.ipynb) |
| 5 | Timer time bases | [Week 5](mcu_notes_week05.ipynb) |
| 6 | PWM | [Week 6](mcu_notes_week06.ipynb) |
| 7 | Theory assessment | [Week 7](mcu_notes_week07.ipynb) |
| 8 | ADC | [Week 8](mcu_notes_week08.ipynb) |
| 9 | ADC and DMA | [Week 9](mcu_notes_week09.ipynb) |
| 10 | I2C and SPI | [Week 10](mcu_notes_week10.ipynb) |
| 11 | UART/USART and SMBus | [Week 11](mcu_notes_week11.ipynb) |
| 12 | Practical assessment 1: GPIO, EXTI, timers, PWM | [Week 12](mcu_notes_week12.ipynb) |
| 13 | Practical assessment 2: ADC and communications | [Week 13](mcu_notes_week13.ipynb) |
| 14 | Review and mock examination | [Week 14](mcu_notes_week14.ipynb) |

The weekly notebooks use a Python 3 kernel for software-based exercises and calculations. Hardware-specific C examples are instructional; build and run firmware from the corresponding STM32 project.
